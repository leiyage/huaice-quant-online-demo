# 淮策 Quant 在线核心功能体验版

本仓库用于 Render 上的公开演示。它保留访客隔离的虚拟回测核心：策略参数与历史回放、绩效与交易证据、稳健性分析、策略对照/消融实验、实验报告与 ZIP 下载，以及明确标注的教学舆情样例。

## 在线版与桌面版边界

- 每个访客拥有独立的内存模拟账户；访客数据不会互相混用。
- 回测只读取仓库内置的历史行情 CSV；不连接券商或交易所，不发送订单，不使用真实资金。
- 教学舆情数据只供独立展示；不是可用于论文验证的真实历史新闻。
- 实验 ZIP / HTML 报告保存在访客会话临时目录；会话闲置 30 分钟后清理，服务重启后也会消失，请及时下载。
- 公开版将重型实验限制为单任务排队式执行；每次最多 500 次重采样、最多 4 个资产，并限制重复提交频率。
- 真实 RSS 采集、CSV 导入、共享数据库、中央任务和本地工作流管理暂时只在桌面版开放。页面对此会显示说明，不会在公网执行。

## 本地运行

安装 `requirements-online.txt` 中的依赖后，在项目目录执行：

```powershell
$env:DEMO_HOST='127.0.0.1'
python demo_server.py
```

浏览器打开 `http://127.0.0.1:8777/`。停止服务请关闭终端。

## 部署

Render 使用 `render.yaml`。公开前请在部署日志和页面中验证健康检查、回测重置、报告、重型稳健性、论文实验 ZIP/报告下载、访客隔离和限流。免费/临时磁盘不保证保存访客生成文件；这版按演示定位处理，不应作为生产交易服务。
